# fitness-coach-mcp

Self-hosted MCP servery pro osobního fitness kouče: **Hevy** (tréninky, rutiny) a **Garmin Connect**
(recovery data, strukturované workouty) za OAuth 2.1 gateway, publikované přes vlastní Tailscale uzel
(Funnel pro claude.ai, tailnet pro Claude Code / Claude Desktop).

> Rozpracováno – kompletní návod doplním.
